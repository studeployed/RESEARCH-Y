## Create or open a project

Open **RESEARCH-Y** from the Windows Start menu. To start a project, type its name, click **Create project in folder**, and choose the folder where you want it saved. RESEARCH-Y creates a new folder inside it and shows the project name. To return later, click **Open project folder** and choose the folder containing `project.ryproj`.

## Set up your first search

1. Under **Research Setup**, enter your **Research theme**. For example, enter *RV Failure*. Under **Research objectives (optional)** you could write *Find studies on right ventricular failure in adults.* Enter your name in **Researcher approving**, then click **Save research heading**.
2. Enter a **New concept group name**, such as *Right ventricular failure*, and click **Add concept group**. A group keeps related search terms together.
3. Inside the group, enter *right ventricular failure* under **New atomic term (single literal)** and click **Add researcher term**. Repeat with *right heart failure* if you want to search for that phrase too. Add one phrase at a time. You can enter all terms yourself.
4. Click **Preview exact broad-OR source queries** and read the wording for each database. An article can match **any** enabled term across the groups. The example objective alone does not limit results to adults. Use **Database selection and optional search limits** to review the available limits.
5. To change the wording, click **Revise draft before approval**. When the preview matches your intent, click **Approve frozen strategy and create pending run**. This saves the search plan. The databases are queried in a later step.

## Run the search and use the results

1. Click **Select run/version** for the saved search, then **Verify saved exact source plan**. Review the checklist answers, lock them and confirm the checklist when ready.
2. Start with a pilot for one group. Preview the PubMed pilot and click **Confirm one PubMed count-only request** to get a match count. The Web of Science Starter pilot has its own preview and confirmation. A pilot gives an estimate. To collect records, use the selected run’s retrieval controls and confirm the work shown in each preview.
3. Read the run progress to see which records have been collected. For PubMed, identifier retrieval finds the records and metadata retrieval brings in their details. Review the publications and any proposed matches before preparing a results workbook.
4. Choose **Prepare strategy workbook** for the search plan or **Prepare reviewed master workbook** for reviewed publication results. Follow the export controls to save the file, then click **Verify workbook**.
