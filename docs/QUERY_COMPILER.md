# P1-03a — Offline source-query compilation

**Status:** implemented and locally tested on `feat/p1-03a-broad-or-query-compiler`, not merged. This is a scientific-method compilation layer, **not** source acceptance, actual retrieval, counting or search verification.

## Approved input and safety boundaries

`compile_source(approved_snapshot, "pubmed"|"wos")` accepts the immutable version-1 JSON snapshot returned by `get_strategy_snapshot`, not an unrestricted draft. The compiler validates `logic="OR"`, researcher identity, source group ordering and per-term approval/provenance. It retains original group membership and omits only terms explicitly disabled in the approved snapshot; a group with no active terms receives no query, **not a fabricated zero hit count**. If all terms are disabled, compilation fails.

The compiler quotes each literal to prevent a term containing an operator word (such as "AND") becoming an unintended Boolean expression. Quote, escape and wildcard syntax that cannot be safely represented as a literal in **both** providers is refused with a reviewable error; it is never silently altered or expanded. Wildcard-enabled searching is not introduced in this increment.

## Source coverage and exact examples

- **PubMed**: `("right ventricle"[All Fields] OR "right-ventricle"[All Fields])`. All terms are individually tagged; no search-term mapping expansion or Medical Subject Headings (MeSH) are deliberately generated by RESEARCH-Y.
- **Web of Science (WoS) Starter**: `TS=("right ventricle" OR "right-ventricle")`. Starter Topic searches title, abstract, author keywords and Keywords Plus; it is narrower than WoS browser All Fields and does **not** search article full text.
- **Union of groups**: each active group's exact query is joined only by `OR`; groups remain separately countable. Original duplicate terms across different groups are preserved, rather than silently removed.

**Critical verification:** PubMed may change the interpretation of quoted phrases absent from its phrase index. Accepted translation, warnings and search sensitivity must be inspected using actual ESearch responses **before a source run is labelled verified**. The compiler does not make that network call. Clarivate Starter `TS` syntax must also be verified using the user's authorised API access; web-interface behaviour is not proof of Starter API acceptance.

## Query-size integrity

`max_query_bytes` is **optional**. No arbitrary undocumented provider limit is assumed. Once the connector has established an applicable source/transport limit, passing that cap splits a group into independently executable, consecutively numbered chunks, at **OR boundaries only**. Each chunk contains complete atomic expressions within the configured UTF-8 byte budget; a single oversized term raises an error, never truncates.

The full-union query remains available for transparent human review, but is marked as exceeding the cap when applicable. **All chunks must be executed**. Chunk-level reported counts cannot be summed to derive a deduplicated result, because the same publication may occur in multiple chunks; retrieve provider IDs and reconcile their union separately.
