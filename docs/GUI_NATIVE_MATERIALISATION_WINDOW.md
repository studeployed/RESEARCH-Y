- **Reply lost *after both original commits*:** the disposable GUI host injects a lost response **only after** the actual original worker has returned from two audited SQLite transactions. The user-facing GUI must show a **RECOVERY REQUIRED** notice and must *not* claim a success receipt, retry confirmation, preserve an old approval or infer zero committed rows. The only continuation is the separate **read-only durable inspection**, which confirms 128 provisional links and four remaining, without new approval.

The controlled Linux test drives the guarded **loopback** HTTP test route with a fixed server-owned action sequence. The Windows test drives the actual **native pywebview window**, waits for the real DOM buttons, enters the synthetic reviewer name in the form field and clicks each user-visible button (including the recovery action). The native harness verifies the displayed recovery notice, source-free aggregate count labels, no injected markup and the absence of a false success outcome. An explicit `--native` option is valid only on Windows. The scenario cannot be supplied by a browser, query string or untrusted JSON; it is a trusted disposable launcher option.

The test-runner independently reopens the original versioned SQLite project after closing the GUI child and checks **132 original source rows**, **132 query/group memberships**, **128 independent provisional publications and association receipts**, **four** remaining unmaterialised originals, original source and membership SHA-256 invariance, foreign keys, SQLite integrity and no automatic merge of same-title/digital-object-identifier records. The [dedicated Linux/Windows Python 3.12 workflow](../.github/workflows/native-window-materialisation.yml) executes both scenarios and retains a short JSON evidence artifact. It runs alongside the existing exhaustive core four-platform test matrix and existing graphical dependency/lifecycle tests. A native click simulation remains **automated feasibility evidence**, not an evaluation by an actual researcher.
